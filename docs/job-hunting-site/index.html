FAQ

Straight answers

What transferable IT skills show up in the code?

PowerShell endpoint triage, DNS/DHCP checks, clock skew for SSO, critical-service reachability, escalation briefs, plus additional authorized TCP reachability tooling and runbook-style docs.

What roles is this aimed at?

IT Services Technician / technical support—where PowerShell, network troubleshooting, documentation, and security hygiene matter. Public work is proof of delivery, not a claim of prior titles.

Is this offensive security?

No. IT triage scripts are endpoint diagnostics. ICS tools perform authorized defensive TCP reachability checks only—not exploits, credential testing, or pen-tests.

What is the IT Triage Toolkit?

Six PowerShell scripts for second-line style work: ranked diagnosis, DNS honesty, auth clock, reach matrix, stack reset with proof, and smart escalation.
