Frequently asked questions

What is ICS OT Protector?

An open-source monorepo of defensive OT/SCADA exposure scanners for water, energy, building automation, and rail. TCP reachability checks only—no credentials or exploit payloads—with JSON reports and remediation metadata.

Is this offensive security or penetration testing?

No. These tools help authorized teams find exposed services via TCP connect checks. They are not an exploit framework, credential tester, or substitute for a full penetration test.

What OT protocols and ports are covered?

Sector catalogs include Modbus TCP, DNP3, BACnet/IP, EtherNet/IP, IEC-related services, and common remote-access ports (RDP, VNC, SSH), with remediation pointers to public CISA/ICS guidance.

What is Nmap for ICS/OT Security?

An open-source howto for installing Nmap and running authorized ICS/OT exposure discovery with OT-safe timing and identity-oriented NSE. Complements ICS OT Protector. No exploit payloads.

What is the ICS/OT Advisories site?

A public feed of current CISA ICS and medical-device advisories. Search by vendor or product, filter by severity, subscribe via RSS, or use the JSON snapshot. Always confirm details on the official CISA page before changing production systems.

What roles is this portfolio aimed at?

OT/ICS security, security automation, and analyst roles where scripting and industrial protocol awareness matter. Source and docs are public on GitHub.

What this work is—and is not

Is

Open-source, defensive TCP reachability scanning and OT-safe Nmap documentation for authorized networks, with sector port catalogs and remediation pointers.

Is not

An exploit framework, credential tester, penetration-testing substitute, or malware detector. No unauthorized use.

Authorized defensive use only. Do not run these tools against systems without explicit asset-owner permission.
