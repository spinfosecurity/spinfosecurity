Main project · PowerShell + Bash · Windows & Linux · MIT

ICS OT Protector

A set of small tools that ask a simple question: can we reach this service on a network we’re allowed to check? They print a structured report with severity so someone else can pick up the work without a long handoff. The domain is industrial networks. The habits that transfer are scripting, networking, and clean documentation.

  • Water & wastewater Interactive checks · clear findings
  • Power grid & substation Subnet checks · common industrial ports
  • Building automation BACnet / BMS exposure review
  • Rail & transit Remote access and protocol checks
  • Scripts over one-offs

    If I’ll do it twice, I write a small tool so the next check matches the last one.

  • Notes someone else can trust

    Findings include severity and who should care—so the ticket doesn’t die in chat.

  • Docs that save time

    Runbooks and a searchable advisories page so people can answer common questions themselves.

A piece of work I’m proud of

I pulled four separate scanners into one project with shared pieces, tests, and a sample report you can review without running a live scan. It isn’t flashy. It’s something another person can clone, run, and understand—with the limits written in plain language.
