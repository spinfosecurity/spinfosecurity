What roles is this aimed at?

Is this offensive security?

No. Authorized defensive TCP reachability checks only. Not an exploit framework, credential tester, or pen-test substitute.

An open-source monorepo of sector scanners (water, energy, building automation, rail) with shared engines and JSON reports. Domain is OT/ICS; craft is automation, networking, and operator docs.
