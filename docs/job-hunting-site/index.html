IT Triage Toolkit

Six scripts for second-line style endpoint work: Why-Broken ranks clock/DNS/disk/path failures; Dns-Truth catches resolver lies; Auth-Clock finds SSO-breaking skew; Reach-Matrix separates path vs app; Stack-Reset heals DNS/DHCP with before/after proof; Escalate-Smart writes a one-page brief for senior IT.

  • Why-Broken Ranked triage before the ticket
  • Auth-Clock Clock skew · SSO / “wrong password”
  • Reach-Matrix Critical services · path vs app
  • Escalate-Smart One-page L3 brief
  • Rank, don’t dump

    Hypothesis #1 with evidence and a suggested fix—not a wall of ipconfig output.

  • Prove the fix

  • Escalate clean

    Impact, what you tried, evidence, one ask—so senior time isn’t wasted.
