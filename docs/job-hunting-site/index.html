Frequently asked questions

What is ICS OT Protector?

An open-source monorepo of defensive OT/SCADA exposure scanners for water, energy, building automation, and rail. TCP reachability checks only—no credentials or exploit payloads—with JSON reports and remediation metadata. Public proof of PowerShell/Bash automation, network troubleshooting, and operator-ready docs.

Is this offensive security or penetration testing?

No. These tools help authorized teams find exposed services via TCP connect checks. They are not an exploit framework, credential tester, or substitute for a full penetration test.

What transferable IT skills show up in the public code?

PowerShell and Bash on Windows and Linux, TCP/IP reachability and port troubleshooting, structured JSON for triage handoffs, runbook-style documentation, Git/GitHub Actions delivery, and security-aware workflows with clear authorized-use limits.

What is Nmap for ICS/OT Security?

An open-source howto for installing Nmap and running authorized ICS/OT exposure discovery with OT-safe timing and identity-oriented NSE. Complements ICS OT Protector. No exploit payloads. Written like an internal runbook.

What is the ICS/OT Advisories site?

A public feed of current CISA ICS and medical-device advisories. Search by vendor or product, filter by severity, subscribe via RSS, or use the JSON snapshot. Always confirm details on the official CISA page before changing production systems.

What roles is this portfolio aimed at?

IT operations, technical support / IT services, and security-aware automation roles where scripting, network troubleshooting, documentation, and security hygiene matter. Source and docs are public on GitHub—not a claim of prior job titles.

What this work is—and is not

Is

Open-source PowerShell/Bash automation, TCP reachability troubleshooting, and operator documentation you can review in public code—including defensive OT/ICS scanners and an OT-safe Nmap guide.

Is not

An exploit framework, credential tester, penetration-testing substitute, or malware detector. Not a claim of Active Directory, ticketing-platform, or helpdesk job history. No unauthorized use.

Authorized defensive use only. Do not run these tools against systems without explicit asset-owner permission.
