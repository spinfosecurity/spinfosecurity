## Flagship project

**[ICS OT Protector](https://github.com/spinfosecurity/ics-ot-protector)** — PowerShell + Bash scanners that prove scripting, TCP reachability troubleshooting, and operator-ready JSON reporting (built for authorized OT/SCADA networks):

| Sector | Scanner |
|--------|---------|
| Water & wastewater | WUP WUP |
| Power grid & substation | Energy Grid Protector |
| Building automation | BAS Guardian |
| Rail & transit | Rail-OT-Protector |

PowerShell + Bash · Windows & Linux · MIT license · TCP reachability only (no exploit payloads)

**Quick review:** [5-minute review guide](https://github.com/spinfosecurity/ics-ot-protector/blob/main/docs/for-employers.md) · [Portfolio](https://spinfosecurity.github.io)

## About

Public automation and documentation work: network checks, triage-friendly output, and security-aware runbooks. The flagship projects target industrial networks; the transferable signal is scripting, troubleshooting, and handoff-ready docs.

**Open to IT operations, technical support / IT services, and security-aware automation roles.**
